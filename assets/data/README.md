# Data files

All gameplay/tuning values. Keys are snake_case. Loaded and validated by `src/core/game_data.gd`.

| File | Schema |
|------|--------|
| `units_stats.json` | `<unit_id>`: `max_hp` (hit points), `speed` (tiles/s), `sight` (tiles), `radius` (tiles, collision/separation), `attack_damage`, `attack_range` (tiles, 0 = melee), `attack_cooldown` (s), `train_time` (s), `cost` ({resource: amount}), `sprite` (key in `render_sprites.json` units), `portrait_icon`, `worker` (can gather/build/repair), `hotkey`, `trained_at`, `description`. |
| `units_movement.json` | Steering tuning (all distances in tiles, times in s): `waypoint_radius` (advance to next waypoint), `arrive_radius` (final stop), `slowdown_distance`, `separation_strength` (push-apart gain), `moving_separation_factor` (moving units yield less), `crowd_arrive_distance` + `crowd_stuck_time` (stop when blocked by a crowd near the goal), `repath_stuck_time`, `formation_spacing`, `path_budget_ms` (max pathfinding time per frame). |
| `players_config.json` | `starting_resources` ({wood, food, gold, stone}), `starting_units` ({unit_id: count}), `starting_buildings`, `colors[]` (`id`, `name`, `primary`/`dark`/`light` hex; index = player slot, also used by the art generator to bake team-coloured sheets). |
| `resources_nodes.json` | `<node_id>`: `resource` (wood/food/gold/stone), `amount` (units of resource held), `sprites` (prop atlas keys, one picked per instance), `blocks` (occupies its tile for pathfinding). |
| `map_generation.json` | `sizes` (name → tiles per side), noise `*_frequency` (cycles across the map), elevation thresholds `*_level` (0–1), moisture thresholds, densities (probability per eligible tile), `start_*` (ring radius as fraction of size; clear radii in tiles), `player_resources` (per-player cluster placement, distances in tiles from the start), `extra_resource_clusters_per_100_tiles_side`. |
| `camera_settings.json` | `pan_speed` (screen px/s at zoom 1), `edge_margin` (px), `zoom_levels` (pixel scale; integers are crispest), `default_zoom_index`, `zoom_smoothing` (exp. smoothing rate). |
| `render_sprites.json` | Sprite sheet layouts shared by the art generator and `SpriteLibrary`: frame size, feet anchor, `portrait_rect` (x, y, w, h inside the first south-facing idle frame, used for UI portraits), animation order (rows = animation × direction), frames, fps; terrain texture order (index = terrain id). |
| `buildings_stats.json` | `<building_id>`: `age` (0 Dark … 3 Imperial, required age), `size` (square footprint in tiles), `max_hp`, `build_time` (s for one villager), `cost`, `population` (pop cap provided when complete), `drop_off` (resources accepted), `trains` (unit ids), `sight` (tiles), `hotkey`, `category` (command page), `description`, `art.style` (painter recipe in tools/art/building_art.gd), `farm_food` (food a farm holds), `walkable` (units can walk over it; farms). |
| `economy_settings.json` | `max_population`, `carry_capacity` (resource units per trip), `gather_rates` (units/s per villager), `gather_animations` (resource → work animation), `work_reach` (tiles from a target's footprint at which work starts), `search_radius` (tiles to look for a replacement node / drop site), `builder_count_formula` ("aoe": n builders build at (n+2)/3 speed), `repair_rate_hp_per_second`, `repair_cost_fraction` (of build cost for a full repair), `train_queue_limit`, `foundation_start_hp`, `auto_reseed_farms` (a depleted farm is restored for its build cost when the owner can pay). |
| `units_stats.json` (combat fields) | `attack_type` (melee / pierce / siege), `attack_damage`, `attack_range` (tiles, 0 = melee), `min_range`, `attack_cooldown` (s between attacks), `armor` ({melee, pierce}; siege uses melee armor), `bonuses` ({class: extra damage}), `classes` (tags bonuses refer to: infantry, cavalry, archer, spear, siege, villager, building), `area_radius` (tiles of splash), `projectile` (arrow / rock), `age` (required age), `auto_attack` (engages enemies in sight when idle), `trained_at`. |
| `buildings_stats.json` (combat) | `armor`, `classes`, `attack` ({damage, range, cooldown, arrows}) for defensive buildings, `researches` (ids in ages.json researched here). |
| `ages.json` | `<age_id>`: `sets_age` (0-3), `requires_age`, `cost`, `research_time` (s), `hotkey`, `description`. |
| `combat_settings.json` | `scan_interval` (s between enemy scans), `leash_extra` (tiles beyond sight a unit chases before returning), `guard_return_distance`, `corpse_seconds`, `rubble_seconds`, `projectile_speeds` (tiles/s), `arc_height_px`, `melee_hit_delay` (s into the swing when damage lands), `retaliate`, `damaged_bar_seconds`, `burn_below_hp_fraction`, `fog_update_hz`. |
| `ai_settings.json` | `think_interval` (s), `resource_split` (target villager share per resource), `difficulties.<easy/normal/hard>`: `gather_multiplier`, `villager_target`, `army_attack_size`, `first_attack_minute`, `military_buildings`, `age_up_villagers` (villagers needed for Feudal/Castle/Imperial), `reaction_radius` (tiles around own buildings defended), `max_army`, `army_mix` (relative weights of unit ids), `max_techs` (technologies researched at most); top-level `tech_priority` (research order). |
| `technologies.json` | `<tech_id>`: `building` (where researched), `age` (required), `cost`, `research_time` (s), `requires` (tech ids), `effects[]` ({`key`, `op` add/mul, `value`}), `description`, `hotkey`, `icon`. Effect keys: `attack_add:<class>`, `armor_melee_add:<class>`, `armor_pierce_add:<class>`, `hp_add:<class>`, `range_add:<class>`, `speed:<class>` (mul), `gather_<resource>` (mul), `carry_capacity` (mul), `build_speed` (mul), `building_hp` (mul), `farm_food_add`. Class `building` targets towers/castle/TC arrows and building armor. |
| `game_rules.json` | `victory_conditions` (conquest / town_center), `default_victory`, `check_interval` (s), `conquest_ignored_buildings` (do not keep a player alive), menu option lists. |
| `game_rules.json` (match setup) | `max_players`, `teams_menu` (number of teams), `starting_resources_menu` (preset id → stockpile), `default_starting_resources`, `population_menu`, `game_speed_menu` (preset id → Engine.time_scale), `default_game_speed`, `reveal_menu` (normal / explored / visible), `min_map_size_by_players` ([players, smallest size]), `wild_animals_menu` (preset id → wildlife multiplier), `default_wild_animals`, `autosave_minutes` (0 = off). |
| `audio_settings.json` | Sound map read by `src/audio/`: `default_volumes` (bus → 0..1), `bus_effects` (reverb), pool sizes and per-key instance limits, `positional` (culling margin, attenuation, zoom gain), `volumes_db` (gain per sound key), unit voices / attack / impact / death sounds by unit id, projectile or class, `fx_sounds` (burst kind → key), `work` (animation → sound, strike point `at` as a fraction of the cycle, `every` n cycles), `building_select`, `notify_sounds`, `music` (playlists per age, battle switch thresholds), `ambient` (loops and one-shots with [min, max] seconds), `loops` (entity-following loops). Keys name files in `assets/audio/` (variants `_1`, `_2`… picked at random). |
| `wildlife_settings.json` | Gaia animals: `claim_radius` (tiles within which a unit claims a herdable), `wander_interval` (s), `wander_radius` / `predator_wander_radius` (tiles), `flee_distance`, `spawn.near_start` (per player: unit, count, ring min/max tiles, group size) and `spawn.wild_per_100_tiles_side` (count per 100×100 tiles, group, `min_from_start`, `near_forest`). Animal stats live in `units_stats.json` (`animal`: herdable / huntable / predator, `food`). |
| `ambience_settings.json` | Day/night: `day_minutes` (real minutes per day), `start_time` (0 = midnight, 0.5 = noon), `tint_keys` ([time, colour] world tint), `night_ranges`, `night_fade`; `lights` (default and per-building colour, radius px, energy); `birds`, `clouds`, `butterflies`, `fireflies` (counts, speeds in px/s, sizes). |
